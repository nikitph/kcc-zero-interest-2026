## Shared house contract for ALL frames (SahkarAI · Hindi · 1080×1920)

- Canvas 1080×1920 (portrait). Root must carry data-width="1080" data-height="1920". Include `<meta charset="utf-8">`.
- Captions are ENABLED: keep-out band is y ≥ 1594. All foreground content must end at y ≤ 1570. Background/ambient layers may be full-bleed.
- Fonts ship as files in `assets/fonts/` (paths relative to project root; reference them as `assets/fonts/...` (project-root-relative; `../../` fails lint)):
  - Noto Sans Devanagari: `noto-sans-devanagari-devanagari-{400,500,600,700,800}-normal.woff2` (Devanagari glyphs, incl. ₹) and `noto-sans-devanagari-latin-{400,500,600,700,800}-normal.woff2` (Latin/digits) — declare BOTH per weight under family "Noto Sans Devanagari" with unicode-range (devanagari: U+0900-097F, U+1CD0-1CF9, U+200C-200D, U+20A8, U+20B9, U+20F0, U+25CC, U+A830-A839, U+A8E0-A8FF, U+11B00-11B09; latin: U+0000-00FF, U+0131, U+0152-0153, U+02BB-02BC, U+02C6, U+02DA, U+02DC, U+0304, U+0308, U+0329, U+2000-206F, U+20AC, U+2122, U+2191, U+2193, U+2212, U+2215, U+FEFF, U+FFFD).
  - Heebo: `heebo-latin-{400,500,700,800,900}-normal.woff2` (Latin + digits). Heebo has NO ₹ — for "₹" wrap it in a span with font-family "Noto Sans Devanagari".
  - Font stacks: Hindi text → `"Noto Sans Devanagari", "Heebo", sans-serif`; numerals/Latin → `"Heebo", "Noto Sans Devanagari", sans-serif`.
  - Devanagari: `letter-spacing: normal` ALWAYS (never track). Headline line-height ≥ 1.18 so matras/shirorekha don't clip; give Devanagari text boxes a little vertical padding (≥ 0.12em) — conjuncts and upper matras overflow tight boxes.
  - Only numerals as "Devanagari digits" where the storyboard shows them (e.g. "बदलाव १ / ४"); otherwise use Western digits in Heebo.
- Palette tokens (define on the frame root as CSS vars): --paper #f3f7fa, --paper-2 #dfe6ee, --ink #0f172a, --body #35455c, --muted #64748b, --faint #94a3b8, --line #e2e9f0, --card #ffffff, --sky #38bdf8, --sky-deep #0284c7, --teal #0d9488, --emerald #34d399, --emerald-deep #059669, --mint #e7f8f1, --skywash #e6f5fd. Ramp gradient: linear-gradient(90deg,#0284c7 0%,#0ea5e9 25%,#0d9488 45%,#10b981 65%,#059669 100%) (for SVG strokes use a linearGradient with the same stops). Ramp colours are SHAPE only; type is ink/body/muted (teal allowed only on numerals ≥ 64px).
- Ground: every frame has a full-duration background clip layer (class="clip", data-start="0", full frame duration) painted --paper, with 1–2 very large circles (diameter 1500–2400px) in --paper-2 / --skywash / --mint positioned so they run off an edge (curved ground). Never dark.
- Cards: #fff, 36px radius, 1.5px solid var(--line), box-shadow: 0 2px 4px rgba(15,23,42,.04), 0 18px 48px -12px rgba(15,23,42,.14).
- CHROME (identical on every frame, 1–11; frame 12 omits it): top-left at left:80px, top:96px — two overlapping 22px circles (sky radial #7dd3fc→#0284c7, and emerald radial #6ee7b7→#059669, the second offset +14px x) then 16px gap, then "SAHKARAI EXPLAINS" in Heebo 700, 24px, letter-spacing .14em, color --muted. Frames 3–9 add a top-right chip (right:80px, top:84px): pill, bg --card with the card shadow, padding 12px 24px, text "बदलाव N / ४" (Noto Sans Devanagari 600, 28px, ink) led by a 30px SVG ring whose ramp arc fills N quarters (frame 3→1, 4→1, 5→2, 6→2, 7→2, 8→3, 9→4). Chrome fades/slides in during 0–0.4s then stays still.
- Halftone (the brand's only imagery): generate deterministically in JS at load (no Math.random — use a seeded function or pure math): an offset dot grid (pitch 14–18px) of SVG circles whose radius is driven by a field (sun glow with exponential falloff, perspective furrows: radius ∝ cos(angle·22)² growing toward the viewer, or a radial swell). Colours only from the ramp (sky/sky-deep above a horizon, teal→emerald below). Keep dot count ≲ 3500 per frame for render speed. Animate a bloom by staggering dot opacity/scale by distance from an origin (use a few grouped rings/bands as tween targets rather than thousands of individual tweens).
- VOICE-ANCHORED TIMING: the Scene lines give real spoken-word times `@t` (seconds from frame start). Start each entrance 0.08–0.15s BEFORE its @t so it is landing as the word is spoken. Count-ups must land their final value on the named word's @t. Nothing enters before its cue; once resolved, hold still.
- Do not add any audio elements. Do not render emblems, seals or letterheads. No emoji. No people.
